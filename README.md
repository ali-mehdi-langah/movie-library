# 🎬 Movie Library

Movie Library is a simple movie information website built using HTML and CSS.

## 📌 About the Project

This project provides information about different movies, including their:

- Story / Description
- Genre
- Director
- Main Actors
- Runtime
- Famous For

Users can select a movie from the main page to view its detailed information.

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🎥 Movies Included

- Interstellar
- The Dark Knight
- Inception
- Avengers: Endgame
- The Matrix
- The Shawshank Redemption
- Titanic
- Spider-Man: No Way Home

## ✨ Features

- Movie cards with posters
- Individual movie information pages
- Navigation between pages
- Hover effects
- Responsive layout
- Custom Movie Library logo
